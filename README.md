# Timun Mas Coffee Lab — Website Preview

Website landing page concept untuk Timun Mas Coffee Lab, Bogor.

Project ini dibuat sebagai portfolio dan website concept untuk menunjukkan
bagaimana brand coffee shop dapat dikembangkan menjadi website yang modern,
editorial, dan responsive.

## Preview

Website dibuat dengan pendekatan visual yang terinspirasi dari karakter
natural, warm, dan premium dari Timun Mas Coffee Lab.

## Features

- Responsive design
- Modern editorial layout
- Hero section
- Story section
- Menu section
- Experience section
- Location / Visit section
- Smooth scrolling
- Scroll reveal animation
- Mobile navigation
- WhatsApp / social CTA
- GitHub Pages deployment

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Project Purpose

Project ini dibuat sebagai website concept untuk menunjukkan kemampuan
dalam membuat landing page untuk bisnis lokal seperti:

- Coffee shop
- Restaurant
- Barbershop
- Clothing brand
- UMKM
- Local business
